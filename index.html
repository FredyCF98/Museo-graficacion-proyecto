1. Evolución y Fundamentos de la Graficación Digital

Autor: Alfredo Chávez Figueroa

Definición de graficación: Es la rama de la ingeniería de software que transforma datos matemáticos y numéricos en representaciones visuales interactivas, superando las limitaciones físicas del hardware mediante algoritmos para facilitar la toma de decisiones y la interacción humano-máquina.

2. Cinco Momentos de la Evolución

Computadora DEUCE (1955)

Limitación anterior: Dificultad para reconocer patrones en volúmenes masivos de datos binarios impresos en papel.

Cambio técnico: Integración de cuatro pantallas CRT circulares como herramienta de diagnóstico interno.

Impacto: Permitió la visualización de datos en tiempo real, agilizando el diagnóstico.

Ejemplo actual: Monitores y dashboards de visualización de datos en tiempo real.

Sketchpad (1963)

Limitación anterior: Restricción a formas geométricas rígidas sin edición de detalles a nivel de píxel.

Cambio técnico: Manipulación directa en pantalla mediante interfaces gráficas primitivas.

Impacto: Sentó las bases fundamentales para el diseño CAD y la edición gráfica.

Ejemplo actual: Software CAD avanzado y tabletas de dibujo digital.

Integración de la GPU

Limitación anterior: Sobrecarga severa del procesador (CPU) al renderizar gráficos, causando retrasos.

Cambio técnico: Desarrollo de hardware dedicado para procesar cálculos de visualización en paralelo.

Impacto: Habilitó la creación de entornos interactivos tridimensionales fluidos.

Ejemplo actual: Tarjetas gráficas para videojuegos AAA y modelado 3D.

WebGL en Navegadores

Limitación anterior: Dependencia de plugins externos inseguros para mostrar gráficos 3D en la web.

Cambio técnico: Adopción de una API nativa para usar la GPU directamente desde el navegador.

Impacto: Mejoró la seguridad, el rendimiento y la compatibilidad universal de gráficos web.

Ejemplo actual: Google Earth web y videojuegos de navegador.

Xerox Alto e Interfaz Gráfica (1973)

Limitación anterior: Interacción exclusiva mediante líneas de texto y comandos de teclado.

Cambio técnico: Implementación de ventanas, íconos y el uso del ratón (mouse).

Impacto: Democratizó el uso de las computadoras haciéndolas visuales e intuitivas.

Ejemplo actual: Los sistemas operativos modernos (Windows, macOS).

3. Una aplicación real

Usuario: Una persona que necesita caminar desde el Museo Comunitario hasta el Parque del Lago.

Problema: Elegir un trayecto a pie de la forma más rápida o conveniente.

Datos: Origen (Museo Comunitario), destino (Parque del Lago) y medio de transporte (A pie).

Representación: Mapa con marcadores O y D, línea azul continua (Ruta A) y gris discontinua (Ruta B), con un panel de texto.

Decisión: Elegir qué trayecto tomar tras comparar tiempo (12 vs 15 min), distancia y calles.

4. Laboratorio de color

Experimento 1 (Caso Acromático): Predicción: Al ser R, G y B iguales, delta será 0 y saturación 0%. Datos: RGB(128, 128, 128) → Cmáx: 128, Cmín: 128, Delta: 0. Conclusión: Al no haber diferencia entre canales, el tono desaparece (0°) dejando solo un valor de gris.

Experimento 2 (Pureza del color): Predicción: Si mantengo el rojo alto pero subo verde y azul, la saturación bajará. Datos: RGB(128, 64, 64) → Cmáx: 128, Cmín: 64, Delta: 64. Saturación cae al 50%. Conclusión: El acercamiento entre canales disminuye la pureza del color, acercándolo al gris.

Experimento 3 (V vs L): Predicción: Valor (V) y Luminosidad (L) darán porcentajes distintos. Datos: RGB(64, 128, 192) → Cmáx: 192, Cmín: 64, Delta: 128. V: 75.3%, L: 50.2%. Conclusión: V depende únicamente del canal mayor, mientras que L usa el punto medio entre el máximo y el mínimo.

5. De la fórmula al algoritmo

Explicación: La normalización ajusta los valores de la escala 0-255 a decimales de 0-1. El Cmáx es el canal más alto y el Cmín el más bajo; su diferencia nos da el delta. En el caso acromático, delta es 0, por lo que carece de color dominante; fijamos el tono en 0 y evitamos dividir entre delta para prevenir errores.


function convertRGBtoHSV(r, g, b) {
  const red = r / 255;
  const green = g / 255;
  const blue = b / 255;
  let cMax = Math.max(red, green, blue);
  let cMin = Math.min(red, green, blue);
  let delta = cMax - cMin;
  let h = 0; let s = 0; let v = cMax * 100;
  if (cMax !== 0) { s = (delta / cMax) * 100; }
  if (delta !== 0) {
    if (cMax === red) { h = 60 * (((green - blue) / delta) % 6); }
    else if (cMax === green) { h = 60 * (((blue - red) / delta) + 2); }
    else if (cMax === blue) { h = 60 * (((red - green) / delta) + 4); }
  }
  if (h < 0) { h += 360; }
  return [Number(h.toFixed(1)), Number(s.toFixed(1)), Number(v.toFixed(1))];
}

6. Glosario

  • Píxel: La unidad más pequeña de color en una pantalla o imagen rasterizada.
  • RGB: Modelo de color basado en mezcla de luz roja, verde y azul para pantallas.
  • HSV: Modelo que separa las características del color en Tono, Saturación y Valor.
  • Tono (Hue): La familia de color puro representada en grados (0° a 360°) dentro de un círculo.
  • Saturación: Qué tan intenso o puro es un color; al 0% se convierte en gris.
  • Valor (Value): El nivel de claridad de un color basado en su canal RGB más alto.
  • Luminosidad: El nivel de luz calculado como el promedio entre el canal mayor y menor.
  • Normalización: Convertir una escala de números a otra más sencilla (ej. 0-255 a 0-1).
  • Delta: Diferencia matemática entre el valor más alto y el más bajo de los canales RGB.
  • Caso límite: Situación extrema (como dividir entre cero) que requiere regla condicional.

7. Conclusión y Fuentes

Conclusión: Antes pensaba que el brillo de un color se medía de una sola forma y que los porcentajes de Valor (V) y Luminosidad (L) siempre serían iguales. La evidencia del experimento con RGB(64, 128, 192) cambió mi idea porque arrojó 75.3% para V y 50.2% para L, demostrando que la percepción de la luz depende de qué variables se aíslan.
